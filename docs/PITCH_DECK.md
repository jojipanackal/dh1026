# Jeera pitch deck

Open [JEERA_PITCH_DECK.html](JEERA_PITCH_DECK.html) in a browser. Use the left
and right arrow keys to present it. The deck is written for a short hackathon
pitch and uses only claims verified in the current demo: four teammates, ten
seeded tasks, five dependencies, the web Agent, the Tasks Graph and Queue, and
the five-minute follow-up worker.

## Suggested talk track

1. **The work between the tasks** — task tools show status, but not the handoff or interruption that explains the status.
2. **Shared memory** — Jeera turns a natural-language update into context, next step, and follow-up timing.
3. **One conversation** — the Agent interprets, reviews, records, and answers from persisted evidence.
4. **Graph demo** — show who is waiting on whom in the landing-page launch.
5. **Context demo** — show that Joji can be interrupted without the task becoming falsely blocked.
6. **Coordination loop** — morning plan, progress, stale-work check-in, handoff, and close with proof.
7. **Deployment story** — web-first today, a separate worker now, Vercel Cron later, external chat channels after the core loop is trusted.
8. **Close** — Jeera makes the real state of work visible and actionable.
